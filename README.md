# Streaming device setup notes

Plain checklists for getting live TV apps working on common devices. Each file covers: network check, app install from the official store, sign-in fields, and fixes for common errors.

## Files

| File | Covers | Status |
|---|---|---|
| [firestick.md](firestick.md) | Fire TV Stick and other Fire TV devices | available |
| [error-codes.md](error-codes.md) | 401 / 403 / 404 / 503 / 511 table | available |
| android-tv.md | Android TV and Google TV | planned |
| samsung-tizen.md | Samsung Smart TVs (Tizen) | planned |
| lg-webos.md | LG Smart TVs (webOS) | planned |
| mag-box.md | MAG set-top boxes | planned |

Menu names change between software versions. Every path in these notes comes from the device maker's own help pages, which are listed at the end of each file.

## Contributions

Open an issue with the device model and the menu path you see.
